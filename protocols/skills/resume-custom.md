# Recover Session Context

Read `AGENTS.md`, applicable nested instructions, and `MEMORY.md`. Then read the
most recent relevant plan in `quality_reports/plans/`, handoff in
`quality_reports/handoffs/`, and session log, when present. Distinguish the
active task from older or completed work.

Inspect `git branch --show-current`, `git status`, `git diff`, and
`git log --oneline -10` to reconcile the notes with actual changes. Recovery
itself is read-only; continue the recovered task under its existing authority.
Flag a memory entry for reconsideration only when its reason may no longer
hold; an expired date alone does not justify deleting it.

Follow `Reports and Updates` in `protocols/writing.md`: state in two or three
sentences the task, completed work, and next step, mentioning only material
uncertainty. Carry on without asking whether to continue; ask only if conflicting
evidence leaves the intended task unclear.
